# Elementum Landing Page

A responsive React-based landing page developed from a Figma design. The project focuses on pixel-perfect UI implementation, reusable components, and seamless responsiveness across desktop, tablet, and mobile devices.

## Features

* Pixel-perfect Figma implementation
* Fully responsive design
* Reusable React components
* Modern and clean UI
* Hover interactions and smooth transitions
* Optimized layout and typography

## Tech Stack

* React
* Vite
* CSS

## Getting Started

```bash
npm install
npm run dev
```

## Build for Production

```bash
npm run build
```
